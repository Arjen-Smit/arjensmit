# arjensmit

Source for [arjensmit.nl](https://arjensmit.nl), hosted on a mijn.host shared hosting package.

- `dist/` — the static site, synced to the web root.
- `api/` — a Node.js API (TypeScript, Express) that runs on the same package and is
  reachable at `https://arjensmit.nl/api`. See [api/README.md](api/README.md).

Working agreements, server layout and deploy commands live in [AGENTS.md](AGENTS.md).
